# Envelope Challenge

A savings tracker for the 100 Envelope Challenge. Number 100 envelopes, draw one at random, and save that many dollars. Fill them all and you've saved $5,050.

**Live site:** https://sattuttle83.github.io/envelope-challenge/

## Features

- Draw a random envelope from the ones you haven't filled, or tap any envelope to fill it yourself
- Track your total saved, how many envelopes and dollars are left, and a one-a-day finish date
- 50 or 100 envelopes, with half, standard or double amounts
- Undo mistakes, and see a list of recent deposits
- Download a backup and restore it on another device

Progress is saved in your browser's local storage, so each browser keeps its own copy. Use **Download backup** and **Restore backup** to move your progress between devices.

It's a single `index.html` with no build step.
